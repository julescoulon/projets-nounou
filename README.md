# projets-nounou

Modèles de bricolage à imprimer.

- `maison-citrouille/` : fenêtres, porte, feuille et queue à découper pour la maison citrouille en assiette en carton, en trois tailles d'assiette (18, 23 et 26 cm). Idée d'origine : [nounoucoindespetits](https://nounoucoindespetits.over-blog.com/2020/10/la-maison-citrouille-assiette-en-carton.html).
  Imprimer `maison-citrouille.pdf` en taille réelle (100 %). Le PDF se régénère avec `python3 gen.py maison-citrouille.html`, puis une impression PDF du HTML.
